# Agent Notes

## Design Context

Before making UI/UX changes (especially on the public marketing site under
`frontend/src/pages` and `frontend/src/components`), read:

- **PRODUCT.md** — register (brand), target users, brand personality, anti-references,
  strategic design principles.
- **DESIGN.md** — color tokens, typography, elevation, and component rules ("The Glass
  Pavilion" system). `.impeccable/design.json` carries extended tokens (tonal ramps,
  motion, component snippets).

DESIGN.md wins on visual decisions; PRODUCT.md wins on strategic/voice decisions.
